## 仓库迁移

- 原 12 个独立仓库已检查 Gitee 远端，后端未提交的邮件服务及部署说明已提交推送。
- 所有本地分支和 tag 已备份推送；每个仓库额外生成并验证了 Git bundle。

## 脱敏及排除

- 将实际服务器地址、服务域名、对象存储地址、数据库凭据、发布密钥及 Apple 开发团队/账号信息替换为示例值。
- Apple 项目开发团队清空；macOS 启动脚本通过 `DEVELOPMENT_TEAM` 接收本机签名团队。
- 管理端、号池和官网会话签名密钥必须显式配置，缺失时拒绝启动，避免空密钥或固定默认值。
- 本地 `.env`、证书私钥、描述文件、数据库备份、用户数据、依赖目录、构建产物、安装包和 IDE 私人状态不进入 Git。含运营凭据与旧协议文案的一次性上传脚本也已移入私有备份，不随源码分发。
- Apple 公共根证书是支付验签需要的公开信任锚，保留并作精确路径例外；不是开发者私钥。
- 三份约 39 MB 的可选扩展词库改为小型示例。基础拼音资源保留，所有纳入文件不超过 5 MiB。
- 两份历史 Orbitron 字体下载实际是 HTML，已排除；第三方基础词库 GPL-3.0 和 Rajdhani 字体 OFL 许可单独保留。

## 发布前运营事项

旧 Gitee 历史和私有备份仍可能含真实凭据。维护者需轮换曾入库的数据库/服务器密码、对象存储和第三方 API 密钥、支付密钥及相关签名凭据。删除源码中的值不能撤销已暴露的凭据。

GitHub 远端由维护者另行提供。设置远端后只推送统一仓库公开历史，不推送备份或旧仓库；按 `RELEASING.md` 开启仓库安全功能。
