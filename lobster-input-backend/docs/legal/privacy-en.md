## Features and data

Depending on enabled features and user actions, the service may process account email, sessions, microphone audio, transcripts and selected text, clipboard text or images, user-triggered screenshots, dictionaries and preferences, device and network information, and diagnostic logs. Not every platform or feature processes all these categories.

List actual fields, purposes, triggers, necessity, and opt-out methods. Explain screenshot, clipboard, accessibility, and keyboard-extension permissions for each platform and actual behavior; do not make blanket claims that these data are never processed.

## External recipients

Cloud ASR, LLM, search, payment, email, and monitoring features may send necessary data to configured providers. Before publication, identify the actual recipients, data categories, purposes, processing regions, and applicable terms. Provide notices and obtain consent where required before the relevant processing. A list of supported integrations is not a list of actual recipients.

## Retention, deletion, and security

Specify what is stored by clients, application servers, databases, logs, backups, monitoring tools, and providers; for how long; and how deletion and exceptions work. Retention periods, cleanup, encryption, and access-control statements must match verified deployment behavior. Do not promise unverified fixed periods or absolute security.

## User rights and contact

Describe applicable access, correction, deletion, withdrawal, account closure, and complaint channels with actual response arrangements. Explain rules for minors, cookies and local storage, cross-region processing, and policy updates. Repository author emails are not automatically privacy contacts for independently hosted services.
