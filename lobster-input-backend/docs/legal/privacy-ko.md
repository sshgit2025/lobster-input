## 기능과 데이터

활성화된 기능과 사용자 동작에 따라 계정 이메일, 세션, 마이크 오디오, 전사 및 선택한 텍스트, 클립보드 텍스트나 이미지, 사용자가 실행한 스크린샷, 사전과 설정, 기기 및 네트워크 정보, 진단 로그를 처리할 수 있습니다. 모든 플랫폼과 기능이 이 데이터를 전부 처리하는 것은 아닙니다.

실제 항목, 목적, 실행 조건, 필요성 및 중단 방법을 명시하세요. 스크린샷, 클립보드, 손쉬운 사용과 키보드 확장 권한은 플랫폼별 실제 동작을 설명해야 하며, 해당 데이터가 절대로 처리되지 않는다고 일괄적으로 약속해서는 안 됩니다.

## 외부 수신자

클라우드 ASR, LLM, 검색, 결제, 이메일 및 모니터링 기능은 설정된 외부 공급자에게 필요한 데이터를 전송할 수 있습니다. 실제 수신자, 데이터 종류, 목적, 처리 지역과 적용 약관을 작성하고 필요한 고지와 동의를 해당 처리 전에 완료하세요. 지원하는 연동 목록과 실제 수신자 목록은 다를 수 있습니다.

## 보관·삭제·보안

클라이언트, 서버, 데이터베이스, 로그, 백업, 모니터링 도구와 공급자가 각각 보관하는 데이터, 기간, 삭제 방법과 예외를 명시하세요. 자동 정리, 암호화와 접근 통제에 관한 설명은 검증한 배포 동작과 일치해야 합니다. 확인되지 않은 고정 기간이나 절대적인 안전을 약속하지 마세요.

## 이용자 권리와 문의

적용되는 열람, 정정, 삭제, 동의 철회, 탈퇴 및 민원 창구와 실제 대응 절차를 설명하세요. 미성년자, 쿠키와 로컬 저장소, 지역 간 처리 및 방침 변경도 안내해야 합니다. 저장소 작성자의 이메일이 자체 호스팅 서비스의 개인정보 문의처로 자동 지정되지는 않습니다.

운영자는 게시 전에 실제 데이터 흐름과 적용 요건을 바탕으로 검토해야 합니다.
