# Lobster Input · 호스팅 서비스 이용약관 템플릿

> 운영자가 내용을 작성하고 검토한 후 게시해야 합니다. 현재 효력이 있는 약관이 아니며, 소스 코드 작성자가 특정 서비스를 운영한다고 약속하는 문서도 아닙니다.

## 운영자와 적용 범위

- 운영자: [OPERATOR_NAME]
- 연락처: [OPERATOR_CONTACT]
- 서비스 주소: [SERVICE_URL]
- 버전 및 시행일: [VERSION] / [EFFECTIVE_DATE]

실제로 제공하는 플랫폼, 기능, 지역과 계정 규칙을 명시해야 합니다. 이용자는 해당 온라인 서비스를 이용하기 전에 최종 약관과 개인정보 처리방침을 확인할 수 있어야 합니다.

## 소스 코드 라이선스

저장소의 자체 작성 코드에는 루트 MIT 라이선스가 적용됩니다. 외부 의존성과 리소스에는 각자의 라이선스가 적용됩니다. 서비스 약관은 해당 오픈 소스 라이선스가 부여한 사용, 복제, 수정, 배포 및 상업적 이용 권리를 제한하지 않습니다. 상표, 외부 서비스 계정과 API 크레딧은 소스 코드 라이선스로 제공되지 않습니다.

## 온라인 서비스 조건

계정 관리, 기능, 요금, 갱신, 해지, 환불, 서비스 중단, 약관 변경과 민원 처리 기준을 실제 서비스에 맞게 작성해야 합니다. 운영자와 이용자에게 적용되는 강행 규정을 검토하고, 확인되지 않은 면책이나 약속을 그대로 사용하지 마세요.

이용자는 타인의 권리를 존중하고 무단 계정 접근, 데이터 취득 또는 서비스 방해를 해서는 안 됩니다. 사용자 콘텐츠의 처리와 보관 범위는 최종 개인정보 처리방침에 명시해야 합니다.

## AI 결과와 이용자 선택

음성 인식과 AI 결과에는 오류가 있을 수 있습니다. 기능의 한계, 외부 서비스 의존성 및 이용 중단 방법을 안내해야 하며, 중요한 결과는 사용 전에 확인해야 합니다.

## 게시 전 확인

운영자, 유효한 연락처, 서비스 범위, 요금과 환불 기준, 분쟁 처리 창구, 버전 및 시행일을 작성하고 실제 서비스 및 소프트웨어 라이선스와 일치하는지 검토하세요.
