# 需求文档

> 本文档基于实际已实现的业务功能反向整理，反映当前版本的真实需求。

## 1. 产品概述

龙虾输入法是一款 macOS 语音输入工具。用户通过全局快捷键触发录音，系统自动完成语音识别、LLM 处理，并将结果填充到当前焦点输入框。支持词典（热词）管理和人设（提示词风格）自定义。

**核心价值**：让用户在任意应用中通过语音高效输入和处理文本。

## 2. 用户认证

### 2.1 统一登录/注册

- 采用邮箱 + 验证码的方式，登录与注册合并为统一流程
- 用户输入邮箱后点击「发送验证码」，系统通过 SMTP 发送 6 位数字验证码
- 验证码有效期 5 分钟
- 若邮箱未注册，验证通过后自动创建账号，默认为「试用版」（trial）
- 若邮箱已注册，验证通过后直接登录
- 登录成功后颁发 JWT Token，有效期 7 天

### 2.2 会话管理

- Token 存储在客户端 UserDefaults 中
- 过期后需重新登录
- 客户端提供退出登录功能

## 3. 语音录音

### 3.1 快捷键触发

- 支持全局快捷键，应用在后台运行时也能响应
- 默认快捷键配置：

| 快捷键 | 操作类型 | 说明 |
|--------|----------|------|
| Fn | transcribe | 语音转文字 |
| Fn + Space | rewrite | 改写选中文本 |
| Fn + Shift | agent | Agent 智能操作 |

- 第一次按下快捷键开始录音，再次按下停止录音并提交处理
- 快捷键可在设置页面自定义修改

### 3.2 快捷键配置

- 支持以下类型的快捷键：
  - 单独 Fn 键
  - Fn + 普通键组合
  - Fn + 修饰键组合
  - 修饰键 + 普通键组合
  - 单独修饰键（Control / Option / Shift / Command）
- 设置界面提供可视化的快捷键捕获控件
- 修改后立即生效，首页快捷键说明同步更新

### 3.3 录音格式与限制

- 录音格式：16kHz 单声道 AAC（m4a），32kbps 码率
- 使用 AVAudioConverter 做高质量重采样（硬件格式 → 16kHz mono PCM → AAC 编码）
- 最大录音时长：客户端 60 秒（到时自动停止并触发处理），后端校验 65 秒
- 60 秒录音约 240KB，远小于 25MB 上传限制

### 3.4 录音体验

- 录音时在屏幕中下方显示浮窗：
  - 半透明、科技感设计风格
  - 实时声纹条形图动画，反映音量变化
  - 浮窗跟随鼠标所在屏幕显示（多屏适配）
- 录音结束后浮窗切换为「识别中」状态：
  - 显示 6 点循环加载动画
  - 识别完成后自动关闭

### 3.5 录音前上下文采集

录音开始前，客户端自动采集以下上下文信息：

| 数据 | 说明 |
|------|------|
| 选中文本 | 通过辅助功能 API 读取当前焦点应用的选中文本 |
| 剪贴板历史 | 最近 5 条文本内容（不足 5 条按实际数量） |
| 目标应用 PID | 记录当前前台应用，用于后续填充 |

## 4. 语音识别与处理

### 4.1 识别流程（AudioProcessPipeline 模板方法）

1. 客户端上传音频文件（16kHz mono AAC m4a）到后端
2. 后端校验文件格式、大小（≤25MB）、时长（≤65秒）
3. 通过 Whisper API 进行语音转文字（支持 OpenAI / Groq 双提供商）
4. Pipeline 判断是否需要调用 LLM（`should_invoke_llm`，当前默认不调用）
5. 若需要 LLM：加载 operation 对应提示词 + 用户人设 prompt，调用 LLM
6. 决定 `action_type`（当前默认 `paste`），返回结果

### 4.2 操作类型

| operation | 提示词模板 | 行为 |
|-----------|-----------|------|
| transcribe | `transcribe.txt` | 语音转文字，直接输出 |
| rewrite | `rewrite.txt` | 根据语音指令改写选中文本 |
| agent | `agent.txt` | Agent 模式，可调用工具 |
| qa | `qa.txt` | 问答模式 |
| summarize | `summarize.txt` | 总结模式 |
| action_extract | `action_extract.txt` | 动作提取 |

### 4.3 LLM 上下文构建

发送给 LLM 的消息包含：

1. **System Prompt**：根据 operation 从模板加载
2. **Selected Text**（可选）：用户录音时选中的文本
3. **Clipboard History**（可选）：录音前剪贴板最近内容
4. **Voice Input**：Whisper 识别的语音文本

### 4.4 多模型支持

- 默认使用 OpenAI GPT-4o
- 支持切换到 Anthropic / DeepSeek / Ollama / Azure OpenAI
- 通过请求参数 `provider` 和 `model` 指定，或使用环境变量默认值

## 5. 结果输出

### 5.1 自动填充

- 后端返回 `action_type` 字段，客户端据此分支执行对应操作
- 当前 `action_type=paste`：处理结果自动写入系统剪贴板 + 模拟 Cmd+V 粘贴
- 需要辅助功能权限
- 若权限不足，首次弹窗申请；被拒绝后本次会话不再重复弹窗
- 无论是否成功填充，结果始终保留在剪贴板中
- 预留扩展：replace（替换选中）、notify（仅通知）、execute（执行命令）等

### 5.2 历史记录

#### 展示

- 默认显示处理结果（result）
- 每条记录提供展开/收起箭头
- 展开后同时显示识别结果（transcript）和处理结果（result）
- 识别结果和处理结果各自带有独立的复制按钮

#### 状态

| 状态 | 说明 |
|------|------|
| pending | 录音完成，等待上传 |
| processing | 上传中 / 识别中 |
| success | 处理完成 |
| failed | 处理失败，显示红色错误提示 |

#### 重试

- success 和 failed 状态的记录均提供「重试」按钮
- 点击重试将本地存储的原始音频重新提交给后端
- 重试成功后更新记录内容
- 若当前有焦点输入框，重试成功后也会自动填充

#### 数据管理

- 历史记录全量存储在客户端本地（JSON 文件）
- 音频文件存储在本地文件系统
- 用户可手动删除单条记录及其音频文件
- 后端不存储历史记录，只返回处理结果
- 采用分页加载优化渲染性能（每页 20 条）

## 6. 权限管理

### 6.1 权限列表

| 权限 | 用途 | 触发时机 |
|------|------|----------|
| 麦克风 | 录音 | 按下快捷键准备录音时 |
| 辅助功能 | 读取选中文本 + 填充输入框 | 按下快捷键准备录音时 / 识别完成填充时 |
| 输入监控 | 全局快捷键监听 | 应用启动时（静默检查） |

### 6.2 权限策略

- **启动时**：静默刷新权限状态，不主动弹窗
- **录音前**：校验麦克风和辅助功能权限
  - 未授权 → 发起系统授权弹窗
  - 被拒绝 → 中断录音操作
- **填充前**：校验辅助功能权限
  - 未授权 → 发起一次授权弹窗
  - 被拒绝 → 跳过填充（本次会话不再弹窗），结果仍在剪贴板
- **手动管理**：侧边栏底部权限图标 + 菜单栏右键「权限管理」

### 6.3 权限状态展示

- 侧边栏底部显示权限状态图标
  - 全部授权：灰色盾牌图标
  - 有未授权：橙色盾牌 + 角标
- 点击弹出权限详情面板，可跳转系统设置

## 7. 客户端 UI

### 7.1 整体布局

- 侧边栏 + 内容区的经典布局
- 侧边栏宽度 180pt，包含：
  - Logo（龙虾图标）+ 应用名「龙虾输入法」
  - 导航项：首页 / 词典 / 人设 / 历史记录 / 设置
  - 录音状态指示
  - 用户信息 + 权限状态 + 退出按钮

### 7.2 首页

- 欢迎信息
- 快捷键使用指南（动态显示当前配置）
- 快速操作入口

### 7.3 历史记录页

- 分页列表展示
- 每条记录显示：操作类型、处理结果、时间、状态
- 展开/收起详情
- 复制、重试、删除操作

### 7.4 词典页

- 顶部标题 + 已用/上限计数（如 5/30）+ 新增按钮
- 列表展示所有热词（标准词），每条带编辑/删除按钮
- 新增/编辑使用弹窗，输入框带字符计数（上限 20 字符）
- 达到上限（30 条）时新增按钮禁用
- 空状态提示引导用户添加
- 热词后续将作为 Whisper prompt 引导语音识别

### 7.5 人设页

- 顶部横幅显示当前激活人设名称
- 左侧人设列表 + 右侧详情区
- 列表项显示图标、名称、内置/自定义标签、激活勾选
- 内置人设：详情区只读，提供「复制并修改」按钮（创建副本进入编辑状态）
- 自定义人设：详情区可编辑名称和风格描述，可删除
- 不允许空提示词（前端禁用保存 + 后端校验）
- 人设 prompt 本质是系统提示词的后半截动态拼接部分，用户无需知道系统还有固定前缀

### 7.6 设置页

- 快捷键配置（可视化捕获）
- 各操作类型的快捷键绑定

### 7.7 窗口行为

- 点击关闭按钮（X）→ 隐藏窗口到后台，不退出进程
- 点击 Dock 图标 → 恢复主窗口到前台
- 菜单栏图标：
  - 左键点击 → 显示/隐藏主窗口
  - 右键点击 → 弹出菜单（显示主界面 / 权限管理 / 退出）
- 录音时菜单栏图标变为彩色波形

### 7.8 后台运行

- 应用启用 App Nap 防护（`ProcessInfo.beginActivity`）
- 确保后台运行时全局快捷键监听不被系统节流

## 8. 后端 API

### 8.1 认证接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/auth/send-code` | POST | 发送验证码到邮箱 |
| `/api/v1/auth/verify` | POST | 验证码确认，返回 JWT Token |

### 8.2 音频处理接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/audio/process` | POST | 上传音频 → Pipeline 处理 → 返回结果 |

请求参数（multipart/form-data）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | 是 | 音频文件（16kHz mono AAC m4a，≤25MB，≤65秒） |
| operation | string | 是 | 操作类型 |
| selected_text | string | 否 | 当前选中文本 |
| clipboard_history | string | 否 | 剪贴板历史（JSON 数组） |
| provider | string | 否 | 模型提供商 |
| model | string | 否 | 模型名称 |

响应：

```json
{
  "operation": "transcribe",
  "action_type": "paste",
  "transcript": "语音识别原文",
  "result": "最终结果文本",
  "model_provider": null,
  "model_name": null
}
```

### 8.3 词典接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/hotwords` | GET | 查询当前用户所有热词 |
| `/api/v1/hotwords` | POST | 新增热词（上限 30 条，单词最长 20 字符） |
| `/api/v1/hotwords/{id}` | PUT | 更新热词 |
| `/api/v1/hotwords/{id}` | DELETE | 删除热词 |

### 8.4 人设接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/personas` | GET | 查询所有人设 + 当前激活 ID |
| `/api/v1/personas` | POST | 新增自定义人设 |
| `/api/v1/personas/{id}` | PUT | 更新人设（内置不可改） |
| `/api/v1/personas/{id}` | DELETE | 删除人设（内置不可删） |
| `/api/v1/personas/active/{id}` | POST | 设置激活人设 |
| `/api/v1/personas/active` | GET | 获取当前激活人设详情 |

### 8.5 快捷键映射接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/shortcuts` | GET | 查询所有映射 |
| `/api/v1/shortcuts/{key}` | GET | 查询单个映射 |
| `/api/v1/shortcuts/{key}` | PUT | 新增或更新映射 |

### 8.6 健康检查

| 接口 | 方法 | 说明 |
|------|------|------|
| `/health` | GET | 返回 `{"status":"ok"}` |

## 9. 非功能需求

### 9.1 性能

- 语音识别 + LLM 处理总耗时应控制在合理范围内
- 历史记录采用分页加载，避免大量数据导致 UI 卡顿
- 音频文件本地持久化，避免网络问题导致数据丢失

### 9.2 安全

- JWT Token 7 天有效期
- 用户接口仅支持 JWT；内部管理接口使用 API Key + HMAC 时间戳签名
- 验证码 5 分钟过期
- 生产环境关闭 Swagger 文档

### 9.3 兼容性

- macOS 14.0+
- 多屏幕环境支持（录音浮窗跟随鼠标所在屏幕）
- 支持 Apple Developer 签名（正式权限授权）

### 9.4 可扩展性

- LLM 提供商可插拔（5 家已接入）
- 语音识别提供商可切换（OpenAI Whisper / Groq Whisper）
- 操作类型通过提示词模板扩展
- action_type 机制支持多种结果处理方式（paste / replace / notify / execute）
- 词典热词可作为 Whisper prompt 引导识别
- 人设 prompt 动态拼接到系统提示词后
- Agent 工具目录预留（`tools/`）
